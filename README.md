# Iris Species Classification using Machine Learning

## Project Overview

This project focuses on classifying Iris flowers into three different species using machine learning.

The project includes Exploratory Data Analysis (EDA), data visualization, model training, and model evaluation.

## Dataset

The Iris dataset contains 150 samples belonging to three species:

- Setosa
- Versicolor
- Virginica

The features used are:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Exploratory Data Analysis

The following analysis was performed:

- Dataset information
- Missing value analysis
- Summary statistics
- Species distribution
- Feature distributions
- Feature relationships
- Pairplot visualization

## Machine Learning Model

A Random Forest Classifier was used to classify the Iris species.

The dataset was divided into training and testing sets.

## Model Evaluation

The model was evaluated using:

- Accuracy Score
- Confusion Matrix
- Classification Report
